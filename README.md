# 壁画微生物处置放行台

壁画微生物处置放行台是供洞穴壁画保护团队在本地使用的浏览器工作台。它把处置案建档、污染证据不可变修订、风险评估、方案安全边界校验、小区试验、偏差裁决、证据冻结、开放安全凭据签发与验真串成一条不可越级的流程，并以连续审计时间线保留每次状态变化。

服务不连接外部系统，图像只登记摘要。业务数据保存在本地 SQLite；expectedVersion 防止并发覆盖，idempotencyKey 保证命令重试得到一致结果。被冻结清单引用的证据、方案和试验不能再修改。

## 环境要求

- Go 1.22 或更高版本
- 支持现代浏览器

## 构建与测试

下载依赖并构建：

    go mod download
    go build ./cmd/server

运行全部测试：

    go test ./...

## 启动

默认只监听高位回环地址 127.0.0.1:19081，数据库文件默认为 mural-release.db：

    go run ./cmd/server

随后访问 http://127.0.0.1:19081/workspace。

可以用 -addr 指定其他回环地址和端口，也可以让 PORT 提供端口号；命令行 -addr 的优先级更高：

    go run ./cmd/server -addr=127.0.0.1:19181 -db=./data/mural.db

也可以先在运行环境中将 PORT 配置为 19182，再执行 `go run ./cmd/server`。

为防止意外暴露本地保护数据，服务拒绝 0.0.0.0 和其他非回环监听地址。

## 有界自检

以下命令会创建临时 SQLite 数据库，启动真实回环 HTTP 监听，通过 JSON API 完整执行“建档→证据→评估→方案→试验→复核→冻结→签发→验真”，检查审计摘要链后关闭服务并删除临时数据库：

    go run ./cmd/server -addr=127.0.0.1:19081 -selfcheck

## 浏览器流程

在 /workspace 中建立处置案后，按状态进度依次提交证据、风险评估、处置方案和小区试验。观察时长达到 72 小时、色差不超过规则阈值且活性降低满足要求后才能申请复核。复核驳回会回到可修订状态，并要求形成新证据修订和复验；复核通过后才能冻结和签发凭据。凭据验真会重新核对有效期、撤销状态、冻结清单摘要和签名摘要。

同源 JSON API 位于 /api/v1。所有修改命令都要求提供 expectedVersion、idempotencyKey 和 actor；规则错误返回稳定错误码，陈旧版本返回 409 Conflict。
